This zip archive contains Stata replication files for Sandefur, Birdsall, Fishkin, and Moyo, "Democratic deliberation & the resource curse: A nationwide experiment in Tanzania."

The program "00 all programs.do" runs all the others.  Before running, adjust the macros in that file to set the file paths used throughout the other programs.

The main data set is "panel_anonymized.dta", which contains pre- and post-treatment survey responses from all experimental subjects. The "moderator_panel_anonymized.dta" file contains responses to a sub-set of the same poll questions, pre- and post-deliberation, administered to the moderators who led the small-group deliberations. The "random_group_lists_anonymized.dta" denotes which individual was assigned to which deliberation group, and is used in estimation of moderator- and peer-effects.

The full text of the survey questions is included in the appendix to the paper.
