# AMR Harmonized Dataset Share

This folder contains the harmonized version of the AMR (Antimicrobial Resistance) survey dataset, processed from its raw SPSS (.sav) format into more universally accessible CSV files, accompanied by comprehensive codebooks.

## Folder Contents

This directory contains the following files:

-   `AMR_harmonized_string.csv`
-   `AMR_harmonized_numeric.csv`
-   `AMR_harmonized_codebook.xlsx`
-   `AMR_harmonized_codebook.pdf`

### `AMR_harmonized_string.csv`

This CSV file contains the primary harmonized dataset. In this version, all categorical variables have been converted from their underlying numeric codes to their corresponding descriptive string labels. This format is ideal for direct readability, exploratory data analysis, and general use where human-readable categories are preferred.

### `AMR_harmonized_numeric.csv`

This CSV file also contains the harmonized dataset, but with categorical variables retaining their original numeric codes. This version is typically preferred for quantitative analysis, statistical modeling, and integration with software that relies on numeric encoding for categorical data.

### `AMR_harmonized_codebook.xlsx`

This Excel spreadsheet serves as a detailed data dictionary for the harmonized dataset. It provides essential metadata for each variable, including:

-   **Variable Names:** The names used in the `AMR_harmonized_string.csv` and `AMR_harmonized_numeric.csv` files.

-   **Variable Labels:** A descriptive label for each variable.

-   **Value Labels:** A mapping of numeric codes to their corresponding string labels for categorical variables.

-   **Data Types:** The enforced data type for each variable (e.g., character, double).

-   **Missing Values:** Definitions of user-defined missing values.

### `AMR_harmonized_codebook.pdf`

This PDF document provides a more comprehensive codebook generated by the `codebookr` R package. In addition to variable labels and value labels, it includes summary statistics, frequency tables, and other descriptive information for each variable, offering a quick overview of the dataset's characteristics.

## Key Variables and Data Structure

The dataset is structured in a **long format**, meaning there are multiple rows per individual, each representing a different time point.

-   **`ID`**: A unique identifier for each individual respondent across all time points.
-   **`Time`**: Indicates the time point or wave of data collection for that specific row.
-   **`Group`**: Identifies the experimental group for each observation. Values are "Treatment" or "Control".
-   **`Weight`**: Survey weights to be applied for statistical analysis. These weights ensure that the sample represents the target population.
-   **`weight_group`**: This variable indicates the specific context (e.g., `Country_Group`) within which the `Weight` variable should be applied. The provided weights (`Weight`) are valid *only within* the specified `weight_group`. Do not combine weights across different `weight_group` categories without careful consideration.

## Usage Notes

-   For general exploration and readability, start with `AMR_harmonized_string.csv`.
-   For quantitative analysis and statistical modeling, `AMR_harmonized_numeric.csv` is recommended.
-   Always consult the `AMR_harmonized_codebook.xlsx` for detailed variable definitions and the `AMR_harmonized_codebook.pdf` for summary statistics and distributions.
-   Remember that the data is in **long format**. Ensure your analysis accounts for this structure and the repeated measures per `ID`.
-   When conducting weighted analysis, apply the `Weight` variable only within its corresponding `weight_group`.
